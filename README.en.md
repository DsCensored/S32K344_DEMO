# S32K344_DEMO

S32K344 Automotive Grade Microcontroller Demo Project, designed based on AUTOSAR architecture.

## Project Introduction

This project is demo code for the NXP S32K344 Automotive Grade MCU, implemented using AUTOSAR architecture. It includes the complete Application Software Layer (ASW), Basic Software Layer (BSW), and Microcontroller Abstraction Layer (MCAL).

### Target Hardware

- **Microcontroller**: NXP S32K344
- **Architecture**: ARM Cortex-M7
- **Development Environment**: S32 Design Studio for ARM

## Directory Structure

### AutoSarNm
AUTOSAR Network Management module implementation, including CAN network management functions.

- `NMmain.c/h` - Network Management Main Program
- `NM.dbc` - CAN Database File
- `NM.ini` - Network Management Configuration File

### S32K344_S32DS/S32K344

Main project directory, containing the following major modules:

#### ASW (Application Layer)
- **Model** - Code generated by Simulink models
- **UserCode** - User application code
  - `ASW_CanCallback.c` - CAN Callback Handling
  - `NvmApp.c/h` - NVM Application Interface
  - `UserCode.c/h` - User Task Entry Point

#### AutoSarNM
AUTOSAR Network Management implementation module.

#### BSW (Basic Software Layer)
- **include** - Header File Directory
  - `App_Info.h` - Application Information Definition
  - `BSW_CanCallback.h` - CAN Callback Interface
  - `BSW_UART.h` - UART Interface
  - `Nvm.h` - NVM Interface
  - `RTE.h` - Runtime Environment Interface

- **src** - Source Code Directory
  - `App_Info.c` - Application Information Management
  - `BSW_CanCallback.c` - CAN Callback Implementation
  - `BSW_UART.c` - UART Driver
  - `Nvm.c` - NVM Management
  - `RTE.c` - Runtime Environment
  - `BSW_WDG.c` - Watchdog Driver

#### MCAL (Microcontroller Abstraction Layer)
Contains the following MCAL drivers:
- CAN (FlexCAN)
- UART/LPUART
- GPT (PIT, STM, eMIOS)
- ICU (ICU, eMIOS ICU, Wkpu)
- Memory (Fee, MemAcc, DFlash)
- And other peripheral drivers

## Main Features

### CAN Communication
- CAN FD Support
- CAN Callback Handling
- Network Management Integration
- Receive/Transmit Channel Management

### Network Management (AutoSarNM)
- BSM (Bus Sleep Mode)
- RMS (Repeat Message State)
- RSS (Ready Sleep State)
- PBSM (Prepare Bus Sleep Mode)
- Fast/Slow State Machine

### NVM (Non-Volatile Memory)
- Internal DFlash + Fee Solution
- Data Block Management
- Block Status Tracking
- Application Data Storage

### Serial Communication
- UART6 DMA Reception
- Frame Detection
- Timeout Handling

### Timers
- Multi-cycle Task Scheduling (2ms, 5ms, 10ms, 20ms, 50ms, 100ms, 1000ms)
- Hardware Timer Support
